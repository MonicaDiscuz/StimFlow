# 设计说明

这份说明记录 StimFlow 当前的实现方式和几个主要取舍。代码改动后以源码为准。

## 目标

StimFlow 只做一件事：把一个本地文件夹里的图片以 Cover Flow 形式全屏展示。它不管理图库，不索引文件内容，不联网。图片文件只读；程序自己只写两样东西：exe 同目录的 `StimFlow.ini` 和可选的缩略图缓存。

## 渲染

渲染用 Direct3D 11。设备按 11_0、10_1、10_0 的顺序尝试创建，交换链是 DXGI flip-model、双缓冲，`Present(1, 0)` 开垂直同步。

整个场景只有一个四边形。每张卡片每次绘制时写一份常量缓冲，包含变换矩阵、视口、透明度和卡片尺寸。一张卡片画四遍：环境阴影、接触阴影、倒影、卡片本身。常规可见卡片 15 张，一帧大约 60 次 draw。

没有深度缓冲。卡片按 `|delta|` 从远到近排序，用画家算法叠上去。卡片数量少，这样比维护深度缓冲简单，也够用。

投影在像素空间做：`w = 1 + z / focal`，`focal = 3.1 × slot_width`。卡片先缩放、再绕 Y 轴旋转、再平移，最后乘投影矩阵。

## 布局

卡片按统一对角线缩放，对角线取 `0.60 × min(屏宽, 屏高)`。中心卡再乘 1.05，邻卡 0.90，越远越小，下限 0.58。所有卡片底边对齐在 `0.72 × 屏高`；最大卡宽 `0.50 × 屏宽`，超宽图等比缩小。

相邻卡片的 x 坐标按实际投影半宽累加，再减去 `0.18 × slot_width` 的重叠量。这样宽图不会互相压扁，代价是宽卡重叠会超过 18%。

背景是一个全屏三角形，径向渐变从 `#101014` 到黑色，加 `±1/255` 的抖动，避免 8-bit 渐变出现色带。

标题用 GDI 画到 32bpp DIB，取 RGB 最大值作为 alpha，再转成 D3D 纹理。查看模式不显示标题。

## 图像与纹理

解码走 Windows Imaging Component。先读 EXIF 方向，按方向旋转，再缩放到目标尺寸，最后把 BGRA 换成 RGBA。

Cover Flow 的纹理窗口是中心 ±8，共 17 个索引。中心 ±1 用 512×768 上限，远景用 256×384 上限；两种都生成 mip，倒影直接采样 mip 做模糊。

窗口滑动时，滑出范围的纹理立即释放。解码是同步的，在 UI 线程里做；大图或慢盘上会有可感知的停顿，这是当前实现最明显的性能取舍。

## 查看模式

进入查看模式时先解码一份 2048 上限的基础纹理，用于 1× 旋转。第一次放大（滚轮或 RT）时再解码 8192 上限的原图，保留在 CPU 内存。

缩放状态只画当前可见区域。原图按 512×512 切块，块按需创建纹理，离开视野就删；没有容量上限，也没有访问时间戳，实际策略是“只保留可见集”。

退回 1× 时释放分块和原图 CPU 缓冲；退出查看模式时释放基础纹理和提示纹理，并调用 `IDXGIDevice3::Trim` 让驱动归还显存。查看模式不写任何磁盘文件。

## 缓存

磁盘缓存只存高分辨率缩略图，也就是中心 ±1 那层。缓存文件用 DPAPI 当前用户加密，文件名是规范化完整路径（小写）的 SHA-256。文件头里有 magic、版本、mtime、文件大小、宽高和数据长度，全部在加密范围内。

写入先写 `.tmp`，再用 `MoveFileEx` 原子替换。读取时校验 mtime 和文件大小，不匹配就删除重来。

缓存目录默认选非系统固定盘里剩余空间最大的那个；找不到就只用内存。退出时弹 A/B/C 选择：保留、清除本次、清除全部。缓存没有容量上限，长期浏览大量图片会一直长。

## 输入

窗口消息处理键盘和鼠标：方向键翻页，空格暂停，M 静音，Esc 退出；滚轮翻页；左键拖动卡片墙，松手后按速度做 fling；点击中心卡进入查看模式。

XInput 每 500 ms 轮询一次，检测到手柄后改成 16 ms。D-pad 和左摇杆按住会连续翻页，重复延迟和间隔读 Windows 键盘设置。手柄 A 暂停，B 退出，X 进入查看模式，Y 静音。

查看模式里，左摇杆旋转或平移，LT/RT 缩放，X 重置旋转，B 分级返回。

## 窗口与模式

主窗口是无边框全屏，固定在主显示器上，`WS_POPUP`，不处理多显示器。DPI 感知设为 Per-Monitor V2。

`.scr` 模式复用 `StimFlow.ini` 里的上次文件夹，不弹选择框。任意键、鼠标移动超过 20 px、点击、滚轮或手柄输入都会退出；不写缓存，不播放音效。

普通模式用 `SetThreadExecutionState(ES_DISPLAY_REQUIRED)` 阻止显示器休眠；`.scr` 模式不阻止。

## 构建与部署

构建用 CMake + MSVC，C++20，静态 CRT。着色器在构建时由 `fxc` 编译成头文件，运行时不需要 `d3dcompiler_47.dll`。音效以 RCDATA 嵌入 exe。发布包只有一个 exe，不依赖 .NET、VC++ 运行库或第三方 DLL。

## 已知限制

- 解码和纹理创建都在 UI 线程同步执行，首次进入大文件夹或首次放大时会卡一下。
- 只支持主显示器，多显示器扩展没做。
- 只支持 WIC 内置格式，HEIC/WebP/AVIF/RAW 会被跳过。
- 缩略图缓存没有容量上限。
- 没有处理 D3D 设备丢失（TDR），设备重置后程序会报错退出。
